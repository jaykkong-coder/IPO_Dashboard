# IPO 주가 퍼포먼스 요인 분석 — 설계 문서

- 작성일: 2026-07-24
- 상태: 사용자 승인 대기
- 용도: 내부 인사이트용 (추후 제안서 소재로 재가공 가능)

## 1. 목적

2024-01-01 이후 신규상장 기업(스팩 제외, 약 186건)을 주가 퍼포먼스 기준으로
Winner / Middle / Loser 그룹으로 나누고, **무엇이 퍼포먼스를 갈랐는지**를
실적·수급·업종·공모구조 등 다각도 변수로 대조 분석한다.
산출물은 ib-report 스타일 PDF 보고서와, 분기마다 재실행 가능한 데이터 파이프라인.

## 2. 분석 대상

- `ipo_companies` 테이블에서 `상장일 >= '2024-01-01'` AND `상장유형 != 'SPAC'`
- 실행 시점 기준 약 186건 (재실행 시 자동 증가)
- 리츠·이전상장·재상장은 DB 구축 단계에서 이미 제외됨

## 3. 퍼포먼스 측정 방법론

### 3.1 수익률 정의
- **주 기준: 확정공모가 대비 수익률** (IPO 투자자 관점, DB 검증 완료)
- 보조 기준: 상장일 시가 대비 수익률 (상장일 갭 제거한 애프터마켓 성과)
- 주가는 pykrx 수정주가 기준. 기준일 종가가 없으면(휴장) 직후 첫 거래일 종가 사용

### 3.2 시장조정 초과수익률
- 종목 소속 시장(코스피/코스닥)의 대표지수 같은 기간 수익률을 차감
- 2024~2026 시장 국면 차이를 제거해 종목 고유 요인을 분리

### 3.3 다중 지평 매트릭스
상장 시점이 제각각이므로 지평별로 경과 종목만 포함:

| 지평 | 표본(2026-07-24 기준) | 역할 |
|---|---|---|
| 1M | 182건 | 초기 수급 국면 |
| 3M | 176건 | 보조 |
| **6M** | **166건** | **주 지표 (그룹핑 기준)** |
| 12M | 129건 | 장기 검증 |
| 상장~현재 | 186건 | 전수 스냅샷 (서열 참고용, 그룹핑 미사용) |

- 결론의 견고성은 **지평 간 일관성**으로 검증 (여러 지평에서 반복되는 패턴만 확정 요인으로 기술)
- 기간별 요인 전환(초기=수급, 후기=실적 등)도 분석 대상

### 3.4 그룹핑
- 시장조정 6M 초과수익률 기준 **3분위: Winner / Middle / Loser**
- 보조: 절대 기준(공모가 상회/하회 유지 여부)
- 지평별 3분위도 각각 계산해 요인 전환 분석에 사용

## 4. 분석 변수

### 4.1 DB 기보유 (수집 불요)
산업분류, 시장구분, 유통가능주식수비율, 기관경쟁률, 의무보유확약비율,
청약경쟁률, 확정공모금액, 신주/구주 비중, 할인율(상·하단), 상단대비확정가비율,
평가방법·적용멀티플, 상장트랙(기술특례 등), 대표주관회사, AI/방산 태그

### 4.2 신규 수집
- **분기 실적**: 상장 직전 회계연도 1분기 ~ 최신 분기. 매출액·영업이익·당기순이익.
  연결(CFS) 우선, 없으면 별도(OFS). OpenDART `fnlttSinglAcnt` REST 직접 호출
  (기존 pipeline.py의 API 키·호출 패턴 재사용. MCP는 스크립트에서 사용 불가)
- 분기 단독값 계산: 반기·연간 보고서는 누적치이므로 직전 분기 누적 차감
- **주가**: pykrx로 종목·지수 시계열 조회 후 지평별 수익률 파생값만 계산 (원시 시계열 저장 안 함)

### 4.3 파생 변수
- **추정치 달성률**: DB `적용이익_백만원`(투자설명서 밸류에이션 근거 이익) 대비
  실제 이익 비율. v1은 상장 익년도 연간 순이익 대비로 단순화하고,
  샘플 20건 수동 검증으로 귀속연도 오차율을 보고서에 명시
- **어닝쇼크 플래그**: 상장 후 첫 2개 분기 중 영업이익 YoY -30% 이하 또는 적자전환
- **업종 내 상대성과**: 동일 산업분류 그룹 수익률 중앙값 대비 초과분
  (업황 효과와 종목 효과 분리 — 예: 반도체 호황기 반도체주 상승분 통제)

## 5. 아키텍처

### 5.1 DB 확장 (ipo_data.db, 테이블 3개 추가)

```sql
quarterly_earnings(
  corp_code TEXT, quarter TEXT,        -- 'YYYYQn'
  fs_div TEXT,                          -- CFS/OFS
  revenue INTEGER, op_income INTEGER, net_income INTEGER,  -- 원 단위, 분기 단독값
  PRIMARY KEY (corp_code, quarter)
)

price_performance(
  stock_code TEXT, horizon TEXT,        -- '1M'/'3M'/'6M'/'12M'/'NOW'
  base_price_type TEXT,                 -- 'IPO'(공모가)/'OPEN'(시초가)
  abs_return REAL, excess_return REAL,  -- %, 시장조정
  index_used TEXT, price_date TEXT,
  PRIMARY KEY (stock_code, horizon, base_price_type)
)

analysis_flags(
  stock_code TEXT PRIMARY KEY,
  group_6m TEXT,                        -- 'W'/'M'/'L'
  estimate_achievement REAL,            -- 추정치 달성률 %
  earnings_shock INTEGER,               -- 0/1
  industry_relative_6m REAL             -- 업종 내 상대성과 %p
)
```

### 5.2 스크립트 (신규 3개)
| 파일 | 역할 | 재실행 동작 |
|---|---|---|
| `collect_quarterly.py` | DART 분기실적 수집 | 증분 수집 (기존 분기 스킵) |
| `collect_prices.py` | pykrx 수익률 계산 | 전체 갱신 (덮어쓰기) |
| `analyze_performance.py` | 그룹핑·그룹 대조 통계 → `analysis_output.json` | 전체 재계산 |

### 5.3 보고서 (ib-report 스킬, A4 가로 PDF)
1. 총론 — 전체 수익률 분포, 시장 국면, 표본 설명
2. 지평별 Winner/Loser 프로파일
3. 요인 딥다이브 — ① 실적·추정치 달성률 ② 유통비율·수급(경쟁률·확약) ③ 업종 ④ 공모구조(밴드 상단 초과·할인율·구주 비중·기술특례)
4. 기간별 요인 전환 (1M→12M)
5. 시사점

## 6. 엣지 케이스

- **상장폐지·거래정지 종목**: pykrx 시계열 중단 시 마지막 거래일 종가로 해당 지평까지만 계산, 이후 지평은 NULL + 플래그
- **분기보고서 미제출**: 신규상장 첫 분기 면제 케이스 존재 → 해당 분기 NULL 허용
- **12월 결산 아닌 회사**: 회계분기와 달력분기 불일치 → DART reprt_code 기준 그대로 저장하고 보고서에 각주
- **적용이익이 EBITDA·매출 등 비순이익 지표인 경우**: 달성률 계산에서 제외(플래그)
- **DART 한도**: 일 20,000콜. 예상 소요 약 1,500~2,000콜로 여유

## 7. 성공 기준

1. 186건 중 분기실적 수집률 90% 이상, 수익률 계산률 95% 이상
2. 지평 간 일관성 검증을 통과한 확정 요인 3개 이상 도출 (또는 "요인 없음"의 명시적 확인)
3. `collect → analyze → 보고서` 사이클이 스크립트 재실행만으로 갱신 가능
4. ib-report PDF 완성 (내부 인사이트 톤)
